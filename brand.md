# Brand — Agent SaaS Starter

_Status: deferred_

Brand setup is intentionally deferred. The web surfaces use a restrained neutral token system and Geist typography so the consuming project can establish its own identity without undoing product-specific styling.

To set up a real brand palette, typography, and voice at any time, run:

    /brand-design

or say: "pick brand colors"

When `brand-design` runs, it will detect this deferred state, skip the "confirm overwrite" step, and proceed directly to the full brand setup. The resulting palette can be applied across the three web apps and this file can be replaced with the real brand documentation.
