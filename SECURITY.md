# Security policy

Report vulnerabilities privately to [saul@saugar.dev](mailto:saul@saugar.dev). Include the affected commit, impact, and steps to reproduce the issue.

Do not post live credentials, private keys, or other people's data in public issues. We will coordinate investigation and disclosure privately.

Security fixes target the latest maintained code. Read the [documented authentication limits](docs/guides/validation.mdx) before deploying.
