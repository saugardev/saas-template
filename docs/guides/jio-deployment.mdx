---
title: Deploy on Jio
description: Create a fresh 2-vCPU deployment and print its public URL.
---

The deployment script creates or reuses a Jio Medium computer (2 vCPU, 4 GiB), builds the monorepo, starts every service, and checks the public endpoints.

```bash
./deploy/jio.sh
```

Progress and the complete endpoint list are written to stderr. The final stdout line contains only the landing URL, so it can be captured directly:

```bash
landing_url="$(./deploy/jio.sh)"
open "$landing_url"
```

Pass an existing Medium computer ID to redeploy it:

```bash
./deploy/jio.sh <vm-id>
```

The script uses the current Git branch and its `origin` remote. Override either value when needed:

```bash
GIT_REPO=https://github.com/you/project.git GIT_REF=feature ./deploy/jio.sh
```

The computer keeps its PostgreSQL volume and OAuth signing keys across redeployments. Destroying the computer removes that state and gives the next deployment new public URLs.

## Connect a client

Open the printed **App** URL, register, and select a project. Then follow [Connect ChatGPT and Claude](../clients/connect.mdx) with the App URL plus `/mcp`.
