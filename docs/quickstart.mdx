## Prerequisites

- Rust 1.94 or newer
- Bun 1.3 or newer
- PostgreSQL
- OpenSSL

## Configure

From the repository root:

```bash
cp .env.example .env
createdb agent_saas_starter
bun install
bun run keys:dev
```

The key script writes a local RS256 keypair under `.local/`. Both files and `.env` are ignored by Git.

## Run

```bash
bun run dev
```

| Service | Local URL |
| --- | --- |
| Product app | `http://localhost:3000` |
| Landing | `http://localhost:3002` |
| Documentation | `http://localhost:3003` |
| Rust API | `http://localhost:4000` |
| MCP | `http://localhost:4001/mcp` |

The API applies embedded PostgreSQL migrations at startup.

## Verify

```bash
bun run check
```

That command lints, type-checks, builds all three web apps, then formats, checks, lints, and tests the Rust workspace.
