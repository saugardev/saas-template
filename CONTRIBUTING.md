# Contributing

Open an issue for bugs or proposed changes, or send a focused pull request. Include reproduction steps and relevant logs without credentials or personal data.

Follow the [quickstart](docs/quickstart.mdx), then run:

```sh
bun run check
```

For authentication or MCP changes, also run the [integration checks](docs/README.md#development-checks) against a disposable database. Add a regression check for behavior changes and update the relevant guide in `docs/`.

Follow our [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities through [SECURITY.md](SECURITY.md).
